# Hydronix Industrial

Professional Grade Assessment for Industrial Rainwater Harvesting & Groundwater Recharge.

## Mobile Testing & Development (How-To)

To view and test this app on your phone while developing in Firebase Studio:

### 1. Make Port Public
1. In the bottom status bar of your Cloud Workstation, look for the **Ports** tab (usually near the terminal).
2. Find port **9002** (the default dev port).
3. Change the visibility from **Private** to **Public**.

### 2. Access the URL
1. Copy the generated `.cloudworkstations.dev` URL.
2. Open this URL in Chrome (Android) or Safari (iOS) on your phone.

### 3. Install as PWA (Native Feel)
- **Android**: Tap the three dots (⋮) in Chrome and select **"Install app"** or **"Add to Home screen"**.
- **iOS**: Tap the **Share** icon (⎙) in Safari and select **"Add to Home Screen"**.
- This will launch the app in full-screen mode without browser UI, allowing you to test it exactly like a mobile application.

## Getting Started

1. **Development**: Run `npm run dev` to start the local server.
2. **Assessment**: Use the interactive form to calculate industrial water collection potential.
3. **Pivoted to Industrial**: This application is specifically configured for industrial scales (m³, large tanks, factory zoning).

## Distribution & Deployment

### Web Deployment (Current Project)
This app is configured for **Firebase App Hosting**. 
- To deploy, connect your GitHub repository to the Firebase Console under the "App Hosting" section.

### Mobile Distribution (APKs)
If you decide to wrap this web app into a mobile application (using tools like Capacitor):
1. **Firebase App Distribution**: Upload your build and add testers by email.
2. **Direct Sharing**: Share the APK via Google Drive or Telegram.
