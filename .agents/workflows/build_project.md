# Build Project Workflow

Follow these steps to install dependencies, perform static typechecking, and create a production build.

## Prerequisites
- Node.js >= v20 installed (`node --version`)

## Steps

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Typecheck Code**
   ```bash
   npm run typecheck
   ```

3. **Build Application**
   ```bash
   npm run build
   ```
